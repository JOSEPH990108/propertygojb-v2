# Approvals

Last updated: 2026-06-12

## Approval matrix
- Low-risk documentation changes: Documentation Agent + one reviewer
- Runtime feature changes: owning agent + System Architect Agent
- Auth or permission changes: owning agent + Security Agent
- Database schema changes: Database Agent + System Architect Agent
- Release/staging promotion: QA Agent + DevOps Agent

Approval status should be recorded in phase progress entries.
