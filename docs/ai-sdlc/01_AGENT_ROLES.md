# Agent Roles

Last updated: 2026-06-12

- Product Manager Agent: defines requirements and acceptance criteria.
- System Architect Agent: protects module boundaries and integration strategy.
- Database Agent: owns schema, migration, and seed safety.
- Backend Agent: implements server actions, APIs, validation, and auth checks.
- Frontend Agent: implements pages, forms, and UI states.
- UI UX Agent: validates usability and visual consistency.
- QA Agent: prepares and executes verification scenarios.
- DevOps Agent: handles CI, deployment readiness, and environment checks.
- Documentation Agent: updates specs, decisions, and progress logs.
- Security Agent: validates auth, permissions, and sensitive data handling.

Each task must have one primary owner and clear definition of done.
