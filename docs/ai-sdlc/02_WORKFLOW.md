# Workflow

Last updated: 2026-06-12

## Standard flow
1. Repository Scan
2. Gap Analysis
3. Phase Planning
4. Agent Task Dispatch
5. Controlled Implementation
6. Verification
7. Progress Report

## Dispatch constraints
- Tasks must be atomic and reviewable.
- Avoid concurrent edits in the same files.
- Include affected files and validation steps before coding.

## Completion criteria
- Required checks pass.
- Docs updated.
- Risks and next task recorded.
